## Requerimiento

1. **Activar completamente el flujo "Recuperar contraseña"** en `/login`:
   - Link "Recuperarla" → pedir email → enviar mail con link.

## Criterios de aceptación

- [x] La pantalla `/login` muestra `V<version>` en un footer chico debajo del card.
- [x] Click "Recuperarla" lleva a `/reset-password` mostrando un input de email (estado `request`).
- [x] Tras enviar el email, muestra confirmación con throttle de 60s en el botón "Reenviar".
- [x] Al volver desde el link del mail, conmuta a estado `update` con form de nueva contraseña + confirmación.
- [x] Las contraseñas se validan por largo (>=6) y matching antes de llamar al backend.
- [x] Tras éxito, hace `signOut` y redirige a `/login` automáticamente.
- [x] Errores del backend (link expirado, password inválido) se mapean a mensaje legible vía `mensajeAuthGenerico`.
